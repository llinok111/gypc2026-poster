# GYPC 2026 — Poster Submission File Host

File host for the poster submitted to the **Global Youth Poster Competition 2026**
(Global Alliance for Human Rights / Youth4Rights, in conjunction with the 6th UN Forum
on Human Rights, Democracy and the Rule of Law).

The print-ready poster PDF is linked from the official entry form. This repository
contains no other project material.

## Files

| File | Purpose |
|---|---|
| `poster.pdf` | A0 portrait, print-ready, referenced by URL from the entry form |
